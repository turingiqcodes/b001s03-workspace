# Requirements Traceability — Airflow Oncall Agent v1.0

Maps every requirement in the SRS baseline (FR-001..FR-078, NFR-001..NFR-039,
AT-001..AT-024) to its implementing module, test and evidence.

**Status rules**

| Status | Meaning |
|---|---|
| Not Started | No implementation yet. |
| In Progress | Partly implemented, or implemented but not yet verified end to end. Evidence says what is done. |
| Implemented | Code complete, no automated test evidence yet. |
| Verified | Implemented and covered by a passing automated test named in Evidence. |
| Verified (mocked HTTP) | Real client verified against recorded API responses served by `httpx.MockTransport`, not against a live system (no live credentials available; see Known limitations in README). |

Module paths are relative to `src/oncall_agent/`. Tests are relative to the project root.
